# Código de conducta

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

En resumen: comentarios respetuosos, sin ataques personales ni
contenido discriminatorio. Los issues y PRs se moderan con ese
criterio.

Contacto: issues públicos para temas de conducta no sensibles;
para denuncias privadas, el email del `SECURITY.md`.
