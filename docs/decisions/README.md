# Decisiones (ADRs)

Un archivo por decisión arquitectónica: `ADR-NNN-titulo.md`.

Convención (misma que en el resto de repos del workspace):

- **Contexto** — qué problema se resolvía.
- **Decisión** — la opción elegida.
- **Consecuencias** — qué queda fácil, qué queda difícil, qué se
  descarta.

Las decisiones no se borran: si se revierten, se marca el ADR como
*Superseded by ADR-NNN* y se crea el nuevo.
